# Meus sites favoritos

## Sobre o projeto
Esta página foi desenvolvida como atividade da Agenda 12 do curso Técnico em Desenvolvimento de Sistemas da Etec.

O objetivo é apresentar cinco sites que fazem parte dos meus interesses e estudos, utilizando HTML e CSS.

## Sites apresentados
- **GitHub:** plataforma para hospedar e compartilhar projetos de programação.
- **Archive of Our Own (AO3):** plataforma de publicação e leitura de histórias de fãs.
- **ChatGPT:** ferramenta de inteligência artificial utilizada para estudar, conversar e revisar textos.
- **Centro Paula Souza:** instituição relacionada aos meus estudos na Etec.
- **Duolingo:** plataforma de apoio ao aprendizado de idiomas.

## Tecnologias utilizadas
- HTML5
- CSS3

## Como visualizar
Baixe ou clone este repositório e abra o arquivo `index.html` em um navegador.
